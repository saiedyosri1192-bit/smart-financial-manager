# المدير المالي الذكي (Smart Financial Manager)

برنامج مالي متكامل ومحترف لإدارة الإيرادات والمصروفات، وتحليل البيانات المالية، وتصدير التقارير، مع دعم تسجل الدخول وقواعد البيانات (SQLite / PostgreSQL).

## الميزات الأساسية:
- **لوحة تحكم تفاعلية:** عرض الإيرادات، المصروفات، وصافي الرصيد.
- **رسوم بيانية تفاعلية:** تحليلات وتوزيع المصروفات والمقارنة المالية باستخدام Chart.js.
- **نظام مصادقة وتأمين:** تسجيل الدخول والتسجيل بكلمات مرور مشفرة و توكن JWT.
- **تصدير تقارير:** تصدير السجلات إلى ملفات Excel (CSV) أو طباعتها وتصديرها كـ PDF.
- **دعم قواعد البيانات:** يعمل تلقائياً بـ **SQLite** محلياً، وبـ **PostgreSQL** سحابياً (عند توفر `DATABASE_URL`).

---

## طريقة التشغيل والعمل السريع محلياً:

1. **فك الضغط** عن المجلد وسحب المجلد في الـ Terminal / Command Prompt.
2. **تثبيت المكتبات البرمجية:**
   ```bash
   npm install
   ```
3. **تشغيل السيرفر:**
   ```bash
   npm start
   ```
4. **فتح البرنامج:**
   افتح المتصفح على الرابط: `http://localhost:3000`

---

## النشر أونلاين على Render:
1. ارفع مجلد المشروع إلى مستودع **GitHub**.
2. أنشئ **Web Service** جديدة على موقع Render وربطها بالمستودع.
3. اضبط أمر البناء (Build Command) ليكون: `npm install`
4. اضبط أمر التشغيل (Start Command) ليكون: `node server.js`
5. (اختياري) أضف متغير البيئة `DATABASE_URL` لرابط قاعدة بيانات PostgreSQL لحفظ البيانات دائماً أونلاين.
